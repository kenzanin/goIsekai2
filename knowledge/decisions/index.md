# Decisions
* [goIsekai2 is a greenfield Go rewrite against the cppIsekai baseline](goisekai-v2-bootstrap.md) - Decisions: cppIsekai is the read-only behavioral baseline (its knowledge bundle + openspec specs), goIsekai V1 is a read-only scraping corpus, bundles never merge, module goisekai2.
* [Adopt gookit/event behind a single-actor bus; separate stream plane](event-dispatch.md) - User ruling 2026-11-21: gookit/event v1.2.0 as dispatch engine, owned by one actor goroutine, async API banned, typed payload facade, drop-oldest stream hub delivered over WebSocket `GET /ws/log`; hand-written hub kept as documented fallback.
* [Use qmuntal/stateless as the FSM engine behind typed domain wrappers](state-machine-engine.md) - User ruling 2026-11-21: qmuntal/stateless v1.8.0 for plugin and job machines instead of a hand-written engine, with typed enums, single owner goroutine, SQLite external state (persist before publish) and graph golden tests; cache entries and daemon lifecycle excluded.
* [Dependency stack: pure Go only (modernc sqlite, tls-client, gopher-lua, quickjs, wazero)](dependency-stack.md) - No-cgo constraint with CGO_ENABLED=0 as build gate; chosen modernc.org/sqlite v1.62.0, bogdanfinn/tls-client v1.18.1, yuin/gopher-lua v1.1.2, modernc.org/quickjs v0.27.0 (V1 evidence supersedes goja) and tetratelabs/wazero v1.12.0; rejection of buke/quickjs-go, wasm3 and the purego native-lib route.
* [Image transcode without libvips: gen2brain WASM-transpiled webp/avif/jxl, pure-Go resize](image-pipeline.md) - Replaces the baseline libvips pipeline with cgo-free gen2brain/webp, gen2brain/avif and gen2brain/jpegxl (libwebp/libavif/libjxl compiled to WASM and transpiled to Go), x/image draw for resize, nodynamic build tag for determinism, plus parity and benchmark gates.
* [chi + coder/websocket for HTTP and WebSocket](http-framework.md) - Use go-chi v5 as the HTTP router and coder/websocket for the log stream, keeping handlers on net/http so middleware and SSR stay stdlib-compatible.
* [Browser host transport and supervision in Go](browser-host-transport.md) - Keep the baseline browser-host tool surface; supervise lightpanda with os/exec and hide the transport behind one Browser interface.
* [chi + coder/websocket for HTTP and WebSocket](http-framework.md) - Use go-chi v5 as the HTTP router and coder/websocket for the log stream, keeping handlers on net/http so middleware and SSR stay stdlib-compatible.
* [Tray as a separate pure-Go command on fyne.io/systray](tray.md) - fyne.io/systray v1.11.0 in its own tray binary: pure Go on Linux (dbus StatusNotifierItem) and Windows, cgo only on macOS; the daemon itself stays pure Go and is spawned as a child.
* [INI config file handled by unknwon.dev/ini/v2](config-file-format.md) - Use unknwon.dev/ini/v2 v2.0.0-beta.7 for reading, merging and saving the goIsekai2 ini instead of a hand-written ordered document model or the v1 package; comments, key order and unknown keys survive, byte-identical formatting does not.
