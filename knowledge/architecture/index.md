# Architecture
* [Event-driven core: domain events on gookit/event, stream plane separate](event-driven-core.md) - Two-plane event architecture: gookit/event managed by a single actor goroutine for domain facts after commit, plus a separate bounded drop-oldest stream hub for SSE; typed facade, event catalog, concurrency contract and gookit internals to defend against.
* [State machines: plugin and job lifecycle on qmuntal/stateless; cache entry and daemon deliberately not](state-machines.md) - Four entity lifecycles with explicit ownership: plugin and job use qmuntal/stateless with typed enums and external SQLite state, image cache entries use a typed enum plus singleflight, daemon uses an ordered slice; persist-before-publish, boot reconciliation, graph golden tests and cppIsekai divergences.
